# EYFlash

Router ve switch güncellemeleri için macOS TFTP/FTP sunucusu.

## İndir

**[EYFlash.dmg (son sürüm)](https://github.com/ercanyuzuk/EYFlash-releases/releases/latest/download/EYFlash.dmg)**

## Kurulum

1. `EYFlash.dmg` dosyasını açın.
2. **EYFlash** simgesini **Applications** klasörüne sürükleyin.
3. Uygulamayı Programlar klasöründen açın.

Gereksinim: macOS 14 veya üzeri (Apple Silicon ve Intel).
Uygulama Apple tarafından notarize edilmiştir ve yeni sürümleri kendisi denetleyip kurar.

Tüm sürümler: [Releases](https://github.com/ercanyuzuk/EYFlash-releases/releases)
